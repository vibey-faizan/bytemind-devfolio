# ByteMind Devfolio - Muhammad Faizan

A hand-written portfolio website. No frameworks, no build step.

**Languages:** HTML, CSS, JavaScript

## Structure

```
bytemind-devfolio/
  index.html                      page structure and content
  css/style.css                   all styling, dark and light themes
  js/script.js                    animations, theme toggle, game, quiz, contact form
  assets/Muhammad_Faizan_CV.pdf   file behind the Download CV button
```

## Run locally

Open `index.html` in a browser. Nothing to install.

## Edit your details

Search the files for these placeholders and replace them:

| Placeholder | File |
|---|---|
| `your.email@example.com` | `index.html` (contact card) and `js/script.js` (`CONTACT_EMAIL`) |
| `github.com/your-username` and `https://github.com/` | `index.html` |
| `linkedin.com/in/your-profile` and `https://www.linkedin.com/` | `index.html` |
| `Source code link coming soon` | `index.html` (Hostel Management System card) |

## Publish on GitHub Pages

1. Create a public GitHub repository named `bytemind-devfolio` and push this folder to it.
2. Repository **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The site goes live at `https://<username>.github.io/bytemind-devfolio/`.
